Quotation stage me revise karne par details pre-fill ni ho rha

-----------------------------------


When you click the "Revise" button and select a Quotation No., the application fetches the existing quotation record from Supabase and populates all form fields through the handleQuotationSelect handler in 

Quotation.jsx
.

Here is the step-by-step technical breakdown of how the data populates:

Step 1: User Selects Quotation No. in UI
Clicking "Revise" in the top header sets isRevising = true.
In 

quotation-details.jsx
, the input field transforms into a searchable dropdown.
When you select a quotation number from the dropdown, handleQuotationSelection calls handleQuotationSelect(quotationNo).
Step 2: Fetching Existing Data from Supabase
In 

Quotation.jsx (Lines 272–276)
, Supabase queries the make_quotations table for the selected Quotation_No:

javascript
const { data, error } = await supabase
  .from("Make_Quotation")
  .select("*")
  .eq("Quotation_No", quotationNo)
  .single();
Step 3: Parsing and Transforming Data
Before populating state, the raw record (loadedData) is formatted:

Reference Names / Consignor: Split by commas if multiple references exist 
Items Array (Items): Maps line items with indexed id fields. If freight description contains specific keywords (e.g. "extra as per"), it sanitizes it (


Calculations: Recalculates subtotal, cgstAmount (9%), sgstAmount (9%), and total (Grand Total)
Special Offers & Notes: |-separated strings stored in database columns are split back into arrays

Step 4: Updating Component State (setQuotationData)
In 

Quotation.jsx 
, setQuotationData populates all form sections:

Quotation Details: quotationNo, date, preparedBy
Consignor Details: consignorState, consignorName (Reference), consignorAddress, consignorMobile, consignorPhone, consignorGSTIN, consignorStateCode
Consignee Details: consigneeName (Company), consigneeAddress, shipTo, consigneeState, consigneeContactName, consigneeContactNo, consigneeGSTIN, consigneeStateCode
Terms & Conditions: msmeNumber, validity, paymentTerms, delivery, freight, insurance, taxes
Bank & Contact Details: accountNo, bankName, bankAddress, ifscCode, email, website, pan
Tables & Lists: items, specialOffers, notes
Finally, handleInputChange updates dependent dropdown values (such as state dropdown selections) so the form UI renders correctly.
