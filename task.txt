When processing a Lead or an Enquiry in the Call Tracker form by selecting Current Stage = "Make Quotation", here is the end-to-end data flow, processing logic, and table/column updates.

1. High-Level Data Flow & Processing Steps
Form Submission Handling:

The user selects the Enquiry Status, enters Customer Feedback, selects Make Quotation, and enters/attaches quotation details.
If a quotation file is attached, it is uploaded to the Supabase Storage bucket (make_quotation), generating a public file URL.
Database Insertion (Audit Log):

A new interaction history record is inserted into the 

enquiry_tracker
 table to maintain log history for the lead/enquiry.
Database Update (Master Record):

Depending on whether the ID belongs to a Lead (starts with LD-) or a Direct Enquiry (starts with EN-/En-), the corresponding main master table is updated:
Leads: 

leads_to_order
Direct Enquiries: 

enquiry_to_order
External Sync (Google Sheets Webhook):

After updating the Supabase database, a manual webhook (

triggerWebhookManually
) triggers an HTTP POST request to Google Apps Script (https://script.google.com/macros/s/...) to sync the updated record to Google Sheets in real-time.
